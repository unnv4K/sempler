MPS-16: проект для сборки APK на GitHub
1. Создай на github.com новый репозиторий (New repository), без README.
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку .github
   (Add file -> Upload files; если .github не загрузилась, создай файл вручную:
   Add file -> Create new file, имя .github/workflows/build.yml, вставь его содержимое).
3. Открой вкладку Actions: сборка запустится сама (3-6 минут).
4. Когда пройдёт, открой запуск и внизу в Artifacts скачай MPS-16-apk (внутри app-debug.apk).
5. Перекинь APK на телефон и установи (разреши установку из неизвестных источников).
